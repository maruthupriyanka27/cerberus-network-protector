Attack Simulator

Generates labelled traffic against the demo site so scoring decisions can be checked against ground truth.

For the real two-PC demo, use the Attack Lab on the CLIENT PC instead — it attacks using that PC's own real IP, so the block actually applies to that PC's browser. This simulator fakes many identities from ONE machine via the X-Sim-Client header, which only works when the server is started with ALLOW_SIM_IDS=1 (single-machine testing/training, not the live demo).

Configuration

Defaults to this machine's own public proxy port. Change this if the proxy runs on a different host (e.g. the deployed VPS) than this admin console.
